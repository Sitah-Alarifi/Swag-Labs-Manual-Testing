# Swag Labs Manual Testing

## Project Overview
This project demonstrates manual software testing of the Swag Labs e-commerce website. The goal was to validate key user flows and identify potential issues through functional and negative testing scenarios.

## Scope of Testing
The testing covered the following areas:
- Login functionality
- Product details
- Shopping cart
- Removing products from the cart
- Checkout information validation
- Successful checkout process

## Test Scenarios

### Login Testing
- Successful login with valid credentials
- Login with invalid credentials
- Login with an empty username
- Login with an empty password
- Login with both fields empty

### Product & Cart Testing
- View product details
- Add a product to the cart
- Verify the product appears in the cart
- Remove a product from the cart

### Checkout Testing
- Checkout with valid customer information
- Complete a successful order
- Checkout with missing first name
- Checkout with missing last name
- Checkout with missing postal code
- Checkout with all fields empty
