# Swag Labs Manual Testing Project

## 📌 Project Overview

This project demonstrates manual software testing of the Swag Labs web application. The testing process covers core functionalities including login, product selection, shopping cart, checkout, and form validation.

The project includes detailed test cases, test execution, and screenshots as evidence of the testing process.

## 🎯 Testing Objectives

- Verify the main functionalities of the application
- Validate user input and form behavior
- Perform positive and negative testing
- Identify unexpected system behavior
- Document test results clearly

## 🧪 Testing Types

- Functional Testing
- Manual Testing
- Positive Testing
- Negative Testing
- Validation Testing

## 🛠 Tools Used

- Swag Labs
- Microsoft Excel
- Google Chrome
- GitHub

## 📸 Test Evidence

Screenshots for each executed test case are included in this repository and named according to their corresponding test case ID (TC-01 to TC-15).
